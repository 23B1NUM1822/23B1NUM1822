## About me

Hi, I'm Sodnomdamba, a computer science student at the National University of Mongolia.

- Right now I'm working on my diploma project, LearnLab AI. It's a platform where students solve coding problems and get feedback on their code.
- I'm also leading a team project: a model intersection where an ESP32 changes the traffic lights based on how many cars are waiting.
- I help build the Magic Code AI website (React on the front, Express and Prisma on the back).
- I actually enjoy writing docs, so most of my repos come with an OpenAPI spec or a small MkDocs site.
- If you want to talk about TypeScript, REST APIs or ESP32 stuff, feel free to email me.
